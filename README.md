# Mussito downloads & support

Mussito 将 iPhone 或电脑麦克风的声音写入 Mac 当前输入框。支持 Mac 本地识别、豆包输入法和本机声纹过滤。

iPhone 首发仍在 App Store 准备中。此仓库仅提供配套 Mac 程序、发行说明及问题反馈。

## 下载

请前往 [Releases](https://github.com/xvshiting/mussito-downloads/releases) 下载。正式 Mac 版需要有效的 Mussito Pro 权益，并通过 iPhone 同步。供 TestFlight / App Review 使用的版本会在文件名标明 ReviewBeta，需使用苹果签名的沙盒购买凭据。

## 安装与要求

- Apple 芯片 Mac，macOS 15 或更新系统；配套 iPhone 需要 iOS 17 或更新系统。
- 解压 ZIP，将 Mussito.app 放入“应用程序”。首次打开按提示允许辅助功能、输入监控及麦克风。
- 豆包模式还需自行安装豆包输入法，在 Mussito 设置中安装随附 Mussito Audio 组件，系统可能要求管理员认证并短暂重启音频服务。
- 本地模型首次使用需下载准备。

## 支持

请通过本仓库 [Issues](https://github.com/xvshiting/mussito-downloads/issues) 反馈问题，提供应用版本、系统版本、识别方式和问题步骤。不要提交密码、配对链接、带密钥二维码、交易凭据或私人录音。

隐私政策与安装说明见 [Mussito 网站](https://xvshiting.github.io/mussito-downloads/)。网站仍处于发布准备阶段时，页面会明确提示。
